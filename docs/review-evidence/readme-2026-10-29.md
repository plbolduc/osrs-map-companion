# README pictures — 29 October 2026

The README pairs each feature with its own picture. Website features are labelled as
website features; these pictures do not imply a Slayer or Sailing task page in the
RuneLite sidebar.

## Plugin pictures

`sidebar-polish-2026-10-29/SidebarPolishShot.java` renders the actual Swing components
with synthetic local state. Its README scenes are `route`, `group`,
`search-whip-card`, `dropluck-card` and `settings-closed`. The two card scenes render
the components themselves, without painting or cropping a replacement interface.

The missing robe in the earlier Drop luck picture was a fixture omission. The live
client's collection catalog resolves the item before it drops; this scene now
supplies the matching item id and the picture provider with the existing game
sprite for Mystic robe bottom (dark). No production behaviour changed.

The Group picture uses level and drop news, which this client produces. The server and
sidebar can display quest and diary news too, but their watched-transition reader remains
deferred, so the README does not advertise those announcements as part of this release.

The retained Stars picture still uses renderer stand-ins for the membership
filter stars. A real client capture can replace it. RuneLite was not launched for
this documentation pass.

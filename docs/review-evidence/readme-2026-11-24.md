## How it was made

The scene and the kept run are the 14 November ones. What differs is the machine: this was painted
on Linux with the build's own JDK 11 toolchain, headless, where every earlier picture was painted
on Windows with JDK 25. From the plugin root, after `./gradlew harnessJar -PruneLiteVersion=1.13.4`:

```sh
cp=$(tr -d '\r\n' < build/harness/classpath.txt)
javac -proc:none -encoding UTF-8 -cp "$cp" -d <classes> docs/review-evidence/sidebar-polish-2026-10-29/*.java
export OSRS_MAP_PUBLIC=../osrs-stars-map/public
java -Djava.awt.headless=true -Duser.timezone=Asia/Bangkok \
  -Dchart.run=docs/review-evidence/chart-run-2026-11-14/kharidian-sea.json \
  -Dlogback.configurationFile=docs/review-evidence/sharing-sidebar-2026-10-11/logback.xml \
  -cp "<classes>:$cp" com.pbolduc.mapcompanion.SidebarPolishShot <out> chart-run
```

No request leaves the machine. The renderer is not a game visit: the run is the map's planner's,
kept beside the 14 November note, and its game values are the scene's.

## What changed in it, and its limitations

Compared with the 14 November picture pixel by pixel, the two differ in three places and nowhere
else:

- the heading's words, *Charting run* where it said *Farm run*, which is the change;
- the fold's arrow at the heading's right, which is a little larger. The arrow is not in the
  RuneScape font, so Java draws it from a system font, and Linux's is not Windows's;
- two pixels in *This leg · 20 tiles*, in the dot, for the same reason.

So the arrow in this one picture is not the arrow in the README's others. Painting it again on the
machine that painted those would put that right; nothing a player reads differs.

The heading's icon is the watering can, as in the plugin: the review asked for the Sailing icon
beside *Charting run*, and that part is not built. The picture shows what the plugin draws.

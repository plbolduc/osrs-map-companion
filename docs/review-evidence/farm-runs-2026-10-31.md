## Relay lifetime follow-up

The first revision counter belonged to memory but did not name whose memory. A server restart
could leave an open client at seven while the new server began at one, stranding every new run.
The red/green regression reproduces that exactly. Replies, stream frames and End's response now
carry a public random relay-memory epoch; new epochs clear the lost run and reset the counter,
and retired epochs cannot return through delayed replies. A malformed marker leaves pairing
secrets and reward acknowledgements readable. Run ready feedback also retires with its run.

The follow-up clean Java 11 / RuneLite 1.13.4 build passes 599 tests. The map's restart mode
(`companion-farm-story.mjs --restart-server`) owns an isolated production server and database,
keeps the same real Java process open, stops and starts only its own server, observes the old
run disappear, then starts a new run at revision one without reconnecting the plugin. It passed.
Game readings remain synthetic. The updated README was checked again at all three phone widths
in both themes, including the new paragraph, with `readme-phone-preview.mjs`.

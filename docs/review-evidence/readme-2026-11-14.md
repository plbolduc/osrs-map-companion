# README pictures — 14 November 2026

Every boss's rates in 1.10.0 give Dagannoth Rex a fourth rated drop, its pet at 1 in 5,000, so the
Drop luck card the README pictures has a row the 13 November picture lacks. This is that one picture
painted again. Every other picture is as `readme-2026-11-13.md` records it.

## How it was made

As on 13 November, with one correction: the README's scene is `dropluck-boss-card`, not
`dropluck-card`, the Aberrant spectre card it was before the Dagannoth Kings had rates
(`readme-2026-11-02.md` says so; the 13 November command line still named the old one). From the plugin
root, after `./gradlew harnessJar -PruneLiteVersion=1.13.4`, on Windows with JDK 25, with `cp` and
`run` set as that record says:

```sh
$run com.pbolduc.mapcompanion.SidebarPolishShot <out> dropluck-boss-card
```

The scene's item catalog is a stub that knows only the names it shows, so it now answers Rex's pet
by name as the real catalog does in the game, and `Sprites.java` gives the pet's id the website's
copy of its picture. Without those two lines the row paints with no picture, which the game would not do.

## How it was made

As on 13 November, with one correction: the README's scene is `dropluck-boss-card`, not
`dropluck-card`, the Aberrant spectre card it was before the Dagannoth Kings had rates
(`readme-2026-11-02.md` says so; the 13 November command line still named the old one). From the plugin
root, after `./gradlew harnessJar -PruneLiteVersion=1.13.4`, on Windows with JDK 25, with `cp` and
`run` set as that record says:

```sh
$run com.pbolduc.mapcompanion.SidebarPolishShot <out> dropluck-boss-card
```

The scene kills Nex 212 times alone, with the platelegs at kill 64, the horn at 120 and the
vambraces at 137 — the case `DropOddsTest` and the map's tests pin. Its item catalog is a stub that
knows only the names it shows, so it answers Nex's table by name as the real catalog does in the
game, and `Sprites.java` gives each of her items the website's copy of its picture; without them a
row not yet had paints with no picture, which the game would not do.
